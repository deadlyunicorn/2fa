Offline 2FA Web Runner

Local offline launcher instructions

If your browser blocks WebAssembly execution over direct file:/// URLs, run the included local runner:

# On Linux or macOS:
./run-offline-web.sh
# On Windows:
run-offline-web.bat
# Or using python directly:
python3 -m http.server 8080 --bind 127.0.0.1
Then open http://127.0.0.1:8080 in your browser. Strictly 100% offline (bound to localhost).
